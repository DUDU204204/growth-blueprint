# Checklist — וובינר מכירתי

> תשתמש ברשימה הזו לפני, בזמן ואחרי כל וובינר. עוקב אחרי [METHOD.md](./METHOD.md).

---

## 🔵 PRE-WEBINAR (שבועיים לפני)

### בניית בסיס
- [ ] ההצעה (Offer) הוגדרה במלואה לפני שכותבים את הוובינר
- [ ] זוהה ה-Big Domino (משפט-טענה אחד מרכזי שאם מקבלים — הכל נופל)
- [ ] מחושב Value Equation: Dream Outcome × Likelihood / Time × Effort
- [ ] מוגדרות 3 האמונות המגבילות שצריך לערער (סוד 1/2/3)
- [ ] מוגדר ה"מי לא מתאים" (סינון = איכות)

### תוכן הוובינר
- [ ] הוק פתיחה חזק (1 מתוך 12 הסוגים) — לא "ברוכים הבאים"
- [ ] כותרת: "[רצון] תוך [זמן] מבלי [התנגדות]"
- [ ] נכתב סיפור חתימה אישי (Personal Signature Story)
- [ ] לכל "סוד" — סיפור / Case Study / נתון
- [ ] נבנה ה-Stack המלא של ההצעה (4-7 מרכיבים + 1-3 בונוסים)
- [ ] הוגדר Risk Reversal ברור
- [ ] הוגדרה דחיפות אמיתית (לא false scarcity)
- [ ] נכתבו 6 שאלות סגירה

### תשתית טכנית
- [ ] בחירת פלטפורמה: Zoom / WebinarJam / סטיקלייט / אחר
- [ ] בנייה של דף נחיתה לוובינר
- [ ] חיבור הדף ל-CRM / רשימת תפוצה
- [ ] בנייה של דף תודה אחרי הרשמה
- [ ] בנייה של דף הצעה (לפעמים זה דף נפרד שעולה אחרי הוובינר)
- [ ] טסט מלא של מעבר ההרשמה: דף → טופס → מייל אישור → קבוצת וואטסאפ
- [ ] רצף תזכורות הוגדר (24h, 2h, 15min, בזמן)

### Pre-launch (Jeff Walker)
- [ ] תוכן Pre-launch — Video/Post 1: The Opportunity (7-14 ימים לפני)
- [ ] תוכן Pre-launch — Video/Post 2: The Transformation (5-7 ימים לפני)
- [ ] תוכן Pre-launch — Video/Post 3: The Ownership Experience (3-5 ימים לפני)
- [ ] הזמנה ספציפית לוובינר (24-48 שעות לפני)

---

## 🟡 DAY-OF (יום הוובינר)

### 60 דקות לפני
- [ ] בדיקת מצלמה ומיקרופון
- [ ] בדיקת תאורה (מאחור = שחור, מקדימה = פנים מוארות)
- [ ] בדיקת רקע (מסודר, ללא דברים מסיחים)
- [ ] טסט אחרון של הסלייד-דק
- [ ] טסט של דף ההצעה (האם הקנייה עובדת? תשלום עובד?)
- [ ] בדיקת חיבור אינטרנט (רצוי כבל ולא Wi-Fi)
- [ ] טלפון על "אל תפריע"
- [ ] מים, נייר ועט קרוב

### 15 דקות לפני
- [ ] שליחת תזכורת אחרונה לקבוצת וואטסאפ
- [ ] התחלת השידור (הקלטה!) — אבל בלי הצגה לקהל עדיין
- [ ] עוד פעם — בדיקת מצלמה/מיקרופון

### בזמן הוובינר
- [ ] התחלה בזמן (לא 5 דקות איחור)
- [ ] הוק בשנייה הראשונה — לא "סליחה אם.."
- [ ] תזכורת לפתוח מצלמות (אם רלוונטי)
- [ ] שאלות אינטראקטיביות כל 5-7 דקות
- [ ] לא ללמד את ה"איך" המלא — רק ה"מה" וה"למה"
- [ ] Segue Question לפני המכירה
- [ ] Permission to Pitch
- [ ] הצגת Stack מלא
- [ ] חזרה על Stack בסיכום
- [ ] הצגת Risk Reversal
- [ ] הצגת דחיפות
- [ ] 6 שאלות סגירה
- [ ] Q&A עם חזרה על הזמנה

---

## 🟢 POST-WEBINAR (אחרי הוובינר)

### תוך שעה
- [ ] שמירת ההקלטה
- [ ] שליחת מייל לכל הנרשמים: "תודה / הקלטה / הצעה"
- [ ] שליחת מייל לרוכשים: "ברוכים הבאים"
- [ ] שליחת מייל לאלו שהיו ולא קנו: "ההצעה תקפה 24h"

### תוך 24 שעות
- [ ] רצף Indecisive: התנגדות מרכזית
- [ ] רצף No-show: "הנה ההקלטה ל-X שעות"
- [ ] עדכון KPIs בגיליון מעקב

### תוך 48 שעות
- [ ] ההצעה נסגרת — מייל סיכום
- [ ] Down-sell אופציונלי לאלו שלא קנו
- [ ] שיחה עם כל מי שקנה (Onboarding)

### תוך שבוע
- [ ] חישוב KPIs מלאים
- [ ] השוואה לוובינרים קודמים
- [ ] זיהוי 3 דברים שעבדו ו-3 דברים שלא עבדו
- [ ] עדכון השיטה / הסקריפט בהתאם
