# צ'קליסט - עיצוב הצעה

> רשימת בקרה לפני שהצעה יוצאת לשוק. עבור מלמעלה למטה. אם נכשלת בסעיף - עצור, תקן, חזור.

## שלב 1 - Gate (האם בכלל לעצב הצעה?)
- [ ] יש בהירות על האווטאר (צעד 3 במצפן הושלם)
- [ ] זיהיתי טריגר ברור לעיצוב הצעה (המרה <10% / השוואת מחיר / מוצר חדש / מעבר מדרגה / שוק זז)
- [ ] ההצעה החלשה היא בעיית עיצוב - לא תסמין של אווטאר מטושטש

## שלב 2 - אימות שוק (4 הסימנים)
- [ ] כאב עצום - הלקוח זקוק לפתרון נואשות
- [ ] כוח קנייה - יש לקהל כסף לשלם
- [ ] קל לאיתור - אפשר למצוא אותם (קבוצות, רשימות, ערוצים)
- [ ] צומח - השוק במגמת עלייה
- [ ] השוק לא נכשל ב-2+ סימנים (אחרת: שנה קהל לפני שתשנה הצעה)

## שלב 3 - אנטומיה (מיפוי הרכיבים)
- [ ] Core Offer מוגדר - מה הלקוח באמת קונה (Dream Outcome ספציפי)
- [ ] Value Stack מפורק לרכיבים נפרדים עם ערך נתפס לכל אחד
- [ ] מבנה Pricing הוחלט (יחיד / good-better-best)
- [ ] Risk Reversal מוגדר
- [ ] Bonuses - כל בונוס מטפל בהתנגדות ספציפית
- [ ] Scarcity / Urgency - מבוסס סיבה אמיתית

## שלב 4 - בחירת דפוס
- [ ] בחרתי דפוס מתאים (Grand Slam / Tiered / Lead Magnet / Subscription)
- [ ] הדפוס תואם את סוג העסק (high-ticket / דיגיטלי / מנוי / פיזי / B2B)
- [ ] כלל-על: מחיר גבוה+אספקה אישית → Risk Reversal+מחסור-קיבולת; עלות שולית נמוכה → tiers+בונוסים+אחריות נדיבה

## שלב 5 - בנייה (כלי טקטי)
- [ ] הרצתי את סדנת ה-grand-slam-builder (בסקיל growth-compass; 9 תחנות מלאות)
- [ ] ה-USP נבנה בכלי usp-xyz (X/Y/Z, עבר מבחן 5 דקות)
- [ ] כל רכיב בסטאק עונה על מכשול אמיתי - אין ניפוח
- [ ] אני יכול לספק כל רכיב באיכות גבוהה (אין הבטחת-יתר)

## שלב 6 - תמחור ועיגון
- [ ] תמחור מבוסס-ערך (לא עלות, לא שעה)
- [ ] בהצעת tiers - האופציה היקרה מוצגת ראשונה כעוגן
- [ ] בדיקת ×10 - המחיר ≤ 1/10 מהערך שהוצג
- [ ] מע"מ 18% מטופל (כפל 1.18), תצוגה שקופה "X + מע"מ"

## שלב 7 - מבחן לחץ (QA)
- [ ] הרצתי את מבחן משוואת הערך (value-equation-test בסקיל growth-compass)
- [ ] ציון 8+ מתוך 11 (פחות = לא יוצא לשוק)

## שלב 8 - מבחן שוק
- [ ] 3-5 שיחות אמיתיות לפני scale
- [ ] לפחות 2/5 סוגרות או נותנות "כן עקרוני"
- [ ] רק אחרי שעבר - מזרימים דלק ממומן

## בקרת קול (חובה בכל פלט שיווקי)
- [ ] אין em-dash/en-dash - רק מקף (-)
- [ ] מחסור/דחיפות אמיתיים בלבד - אין fake
- [ ] קונקרטי, בשפת הלקוח - לא בנאלי
- [ ] לשון זכר / נטרל
