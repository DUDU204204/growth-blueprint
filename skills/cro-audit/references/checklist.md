# צ'קליסט - אודיט CRO

> רשימת בקרה תפעולית. עוברים אזור-אזור, בסדר. כל פריט שלא מסומן = חיכוך פוטנציאלי שמפיל המרה.

## 0. איסוף נתונים (לפני שמתחילים)
- [ ] יש אווטאר מוגדר - מי הקהל, באיזה שלב מודעות (בלי זה האודיט = ניחושים)
- [ ] GA / Plausible - אחוז המרה, bounce rate, מקור טראפיק
- [ ] Heatmap (Hotjar/Clarity) - איפה עוצרים, איפה סוגרים
- [ ] Session recordings - צפיתי ב-5-10 ביקורים אמיתיים
- [ ] EPC / ROAS - מה המטרה הכלכלית (EPC לפני אחוז המרה)
- [ ] אם חסר נתון - מצוין במפורש בדוח: "פעלתי על עקרונות, בלי נתוני X"

## 1. Above-the-Fold / Hero ("זה בשבילי?" - 0-3 שניות)
- [ ] כותרת ראשית מכילה 3 רכיבים: סקרנות + ספציפיות + רלוונטיות
- [ ] כותרת ראשית מתאימה לשלב המודעות של הקהל בפועל (Schwartz)
- [ ] תת-כותרת מרחיבה, לא חוזרת על הכותרת
- [ ] ויזואל Hero תומך במסר, לא מסיח
- [ ] CTA ראשוני גלוי בלי לגלול - חד, פעולה יחידה
- [ ] Trust signals (לוגואים/מספרים) מופיעים כבר כאן

## 2. מסר / הצעה
### Hook ("זה שווה?" - 3-15 שניות)
- [ ] Hook מושך את הקורא פנימה, לא מציג עדיין את המוצר
- [ ] רגש קודם, היגיון אחריו - פותח בכאב/סקרנות, לא בנתונים
- [ ] מיתוג הכאב - יש שם לכאב שהקהל יזדהה איתו
- [ ] ניגוד - "רוב האנשים עושים X, אנחנו מציעים Y"

### Story ("זה בטוח?" - 15-45 שניות)
- [ ] Epiphany Bridge - סיפור של רגע הארה (7 רכיבים)
- [ ] זהות ברורה - מי הכותב/המוצע ולמה דווקא הוא
- [ ] אורך הולם - לקהל Cold ארוך יותר, לא ארוך/קצר מדי

### Offer ("זה יעבוד אצלי?")
- [ ] ההצעה עומדת ב-5 הקריטריונים: מובנת, מדידה, מוגדרת בזמן, בעלת ערך, חדשנית
- [ ] Value Stack - פירוק ההצעה לרכיבים עם תמחור
- [ ] אפקט האווז - מחיר עוגן לפני המחיר הרצוי
- [ ] USP חד - אפשר לומר אותו במשפט אחד

## 3. חיכוך
- [ ] שדות בטופס במינימום ההכרחי (כל שדה נוסף = נפילה בהמרה)
- [ ] אין דחיפות מזויפת (טיימר שמתחדש, "נשארו 2 מקומות" בלי בסיס) - פוגע בהמרות
- [ ] הדף לא נכשל באף אחת מ-5 מיקרו-ההחלטות (בשבילי / שווה / בטוח / יעבוד / מה אם לא)
- [ ] אין פער שלב-מודעות: הדף כתוב לשלב שבו הקהל נמצא בפועל

## 4. הוכחה חברתית
- [ ] לפחות 3 עדויות, כל אחת עם שם + תמונה + תוצאה ספציפית
- [ ] Social Proof במספרים ("840 לקוחות", "מעל 12,000 משתמשים")
- [ ] Authority - פרסומים בתקשורת, לוגואים של לקוחות, הסמכות
- [ ] דמונסטרציה - סקרין-שוט של תוצאה / וידאו של התהליך
- [ ] Before/After עם מספרים

## 5. CTA ("מה אם לא?" - הסרת חיכוך אחרון)
- [ ] CTA חד - פעולה אחת בלבד, לא "למד עוד וגם תקנה וגם"
- [ ] ניסוח תוצאתי - "קבל את התוכנית שלי" עדיף על "לחץ כאן"
- [ ] Risk Reversal - החזר כספי / ניסיון חינם / הבטחה ברורה
- [ ] FAQ - 5-7 התנגדויות נפוצות עם תשובות
- [ ] דחיפות אמיתית - אם יש דד-ליין, הוא אמיתי

## 6. מובייל
- [ ] הדף נראה תקין במובייל (70%+ מהטראפיק) - לא רק בדסקטופ
- [ ] כפתורים מספיק גדולים, טקסט קריא
- [ ] טפסים עובדים במובייל
- [ ] CTA ראשוני גלוי במובייל בלי לגלול

## 7. מהירות
- [ ] PageSpeed Insights מעל 80 במובייל
- [ ] טעינה מתחת ל-1.2 שניות במובייל (מעל = נפילה של 20%+ בהמרה)

## 8. מדידה / UTMs
- [ ] יש מדידת אחוז המרה ו-EPC על הדף
- [ ] Scroll depth - הקהל מגיע לסוף (לבדוק ב-heatmap)
- [ ] מקור הטראפיק מתויג (UTMs) כדי לדעת מה ממיר

## 9. Exit-Paths ("אין cul-de-sacs")
- [ ] לכל מי שלא קונה יש צעד הבא (לא מבוי סתום): שיחת ייעוץ / הורדת מדריך / הצטרפות לרשימה
- [ ] ב-B2B - תפקיד הדף לעבור לשלב הבא, לא לסגור לבד

## לפני הגשת הדוח
- [ ] בוצע Cross-Check מול שפה-ומושגים (שלב 8) - בלי לדלג על סעיף
- [ ] הובאו בדיוק 5 ההצעות הכי חזקות שמקדמות את המטרה העסקית
- [ ] כל הצעה כוללת: עיקרון מהגלוסרי / מה קורה היום / מה לעשות / למה זה יזיז מטרה / ICE
- [ ] לכל שינוי צוין KPI צפוי (למשל "צפוי להעלות CR מ-3% ל-4.5%")
- [ ] לא הומלץ שינוי בלי הסבר על סמך מה (נתון / עיקרון / דוגמה)
- [ ] הדוח קצר מספיק לקריאה ב-10 דקות, עם TL;DR של 5 ההצעות בראש
