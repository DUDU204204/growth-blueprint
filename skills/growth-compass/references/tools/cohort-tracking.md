# Cohort Tracking — מעקב קוהורט

> מודדים לקוחות לפי **חודש הצטרפות** (Cohort) ועוקבים אחריהם לאורך זמן. הדרך היחידה לראות באמת אם Churn יורד, אם Onboarding משתפר, ואם הצמיחה אמיתית או רק נראית כך.

## למה Cohort Tracking
**הגרף הנפוץ:** Revenue חודשי לאורך זמן. נראה יפה — עולה. **השאלה האמיתית:** עולה כי לקוחות חוזרים, או כי קונים חדשים מסתירים את הנטישה?

**Cohort מענה:**
- כמה מ-50 הלקוחות שהצטרפו בינואר נשארו בפברואר? במרץ?
- האם הקוהורט של מאי "חי יותר זמן" מהקוהורט של ינואר? (=Onboarding משופר)
- כמה ARPU של קוהורט נוכחי vs ישן? (=Pricing/Upsell עובדים)

## טבלת Cohort בסיסית

```
        | חודש 0 | +1   | +2   | +3   | +4   | +5   | +6   |
--------|--------|------|------|------|------|------|------|
ינואר   | 50     | 47   | 44   | 42   | 39   | 37   | 35   |
פברואר  | 60     | 56   | 53   | 50   | 47   | 45   |      |
מרץ     | 75     | 71   | 68   | 65   | 62   |      |      |
אפריל   | 80     | 76   | 73   | 70   |      |      |      |
מאי     | 90     | 85   | 81   |      |      |      |      |
יוני    | 95     | 90   |      |      |      |      |      |
```

**מה רואים:**
- כל קוהורט מתחיל בגודל שונה.
- ב-+1 (חודש אחרי הצטרפות): שמירה של ~94% בכל קוהורט.
- ב-+6: ינואר ירד ל-70%.

## Metrics שמחושבים מ-Cohort

### 1. **Retention Rate** (אחוז שנשארו)
```
Retention(N) = לקוחות פעילים בחודש N / לקוחות שהצטרפו בחודש 0
```

דוגמה ינואר חודש 6: 35/50 = 70% retention.

### 2. **Churn Rate** (אחוז שעזבו)
```
Churn(N) = 1 - Retention(N)
```

ינואר חודש 6: 30% churn.

### 3. **Net Revenue Retention (NRR)**
לא רק כמה לקוחות נשארו — כמה הכנסה מהם.
```
NRR(N) = הכנסה מקוהורט בחודש N / הכנסה מקוהורט בחודש 0
```

- **NRR > 100%** = הקוהורט מגדיל הוצאות לאורך זמן (upsells > churn). **חלום.**
- **NRR < 100%** = נטישה גוברת על upsell.

### 4. **CLV (Cohort Lifetime Value)**
LTV מחושב מ-cohort אמיתי, לא הערכה מ-ARPU/Churn.
```
CLV = sum(revenue ממוצע × לקוחות בחודש N) לאורך כל חודשי הקוהורט
```

### 5. **Time to Payback**
כמה חודשים עד שהקוהורט מחזיר את ה-CAC שלו?
```
Payback Month = החודש שבו cumulative revenue / cohort size > CAC
```

טוב: ≤6 חודשים. מעולה: ≤3 חודשים.

## ניתוח Cohort בפועל

### דוגמה — מועדון מנויים

```
        | חודש 0 | +1   | +2   | +3   | +4   | +5   | +6   |
--------|--------|------|------|------|------|------|------|
Q1 2026 | 100    | 85   | 75   | 68   | 64   | 60   | 58   |
Q2 2026 | 120    | 110  | 102  | 96   | 92   |      |      |
Q3 2026 | 150    | 145  | 140  | 135  |      |      |      |
```

**מה רואים:**
- Q1 איבד 42% תוך 6 חודשים. אזעקה.
- Q2 שיפור משמעותי: -8% בחודש 1 (vs -15% ב-Q1).
- Q3 כמעט אין נטישה בחודש הראשון.

**מסקנה:** Onboarding שיפרנו ב-Q2-Q3 → רושם בקוהורטים החדשים. **לא** משתקף ברוונה החודשית (כי הקוהורטים הישנים עדיין שולטים בנתון), אבל cohort tracking מגלה את ההתקדמות.

## איך מתחילים — צעדים פרקטיים

### שלב 1 — Setup ב-Sheet/Airtable
- עמודה 1: ID לקוח
- עמודה 2: תאריך הצטרפות
- עמודה 3-N: סטטוס בכל חודש ("פעיל" / "עזב" + סכום)

### שלב 2 — חישוב חודשי
- בכל סוף חודש: עדכן את הסטטוסים.
- חשב Retention/Churn לכל קוהורט.

### שלב 3 — Visualization
- Cohort Chart (heatmap) ב-Google Sheets / Airtable / Mixpanel / Amplitude.
- צבעים: ירוק=שמירה גבוהה, אדום=נטישה גבוהה.

### שלב 4 — ניתוח חודשי (30 דק')
שאלות:
- האם הקוהורט החדש שומר טוב יותר מהישן?
- איפה בדיוק הנטישה? חודש 1? 3? 6?
- מה השתנה בקוהורט שיותר חזק?

## הטעויות הקלאסיות

1. **רק לראות "Revenue Growth"** — לא מבחין בקוהורטים. הצמיחה יכולה לבוא רק מקוהורטים חדשים גדולים שמסתירים נטישה.
2. **לא לעשות שום שינוי בתגובה** — Cohort tracking ללא פעולה = analytics אקדמיים.
3. **לא לסגמנט** — כל הלקוחות באותו קוהורט. אבל אם יש 3 סוגי לקוחות (B2C/B2B/Enterprise), כל אחד שונה.
4. **לעצור אחרי 3 חודשים** — נטישה אמיתית נראית רק אחרי 6-12 חודשים.

## כלים

- **Mixpanel / Amplitude** — מתאים מ-1,000+.
