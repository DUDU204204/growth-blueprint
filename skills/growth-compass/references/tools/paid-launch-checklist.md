# Paid Launch Checklist — צ'קליסט השקה משולמת (Meta / Google / TikTok)

> לפני שמשקיעים ₪10K+ ב-Paid Ads — 30 דברים שחייבים להיות במקום. אחרת = שריפת תקציב.

## למה צ'קליסט הזה
**הסטטיסטיקה:** 70% מהקמפיינים החדשים מבוזבזים בשבוע הראשון בגלל **בעיות שאפשר היה לחזות מראש** — קופי לא ממוקד, דף נחיתה גרוע, tracking לא מוגדר.

הצ'קליסט מבטיח שאם הקמפיין נכשל — זה בגלל שוק, לא בגלל הכנה.

## 4 קטגוריות — 30 פריטים

### 📍 קטגוריה 1 — אסטרטגיה ושוק (8 פריטים)

- [ ] **1. מי האווטאר?** ראיון אווטאר עם 5+ לקוחות עבר. כתוב.
- [ ] **2. מה הכאב?** כתוב ב-3 משפטים. מבוסס על מילים מהלקוחות.
- [ ] **3. מה ההצעה?** ברורה, מדידה, בזמן, בעלת ערך, חדשנית (5 קריטריונים).
- [ ] **4. מה ה-USP?** "אני עוזר ל-X להשיג Y בלי Z" — כתוב ובדוק "האם בינארי ברור?"
- [ ] **5. מה ה-Awareness Level?** Unaware / Problem-Aware / Solution-Aware / Product-Aware / Most-Aware (Schwartz).
- [ ] **6. תקציב חודשי מוקצב?** ₪X לחודש מינימום 3 חודשים. אם ≤₪3K — לא Paid.
- [ ] **7. ROAS target?** מינימום 2-3x ברק 1, 4-6x ב-mature campaigns.
- [ ] **8. ימי החיים של הליד?** 14 יום (cold sales) / 90 יום (warm sequence) / 6+ חודשים (long sales cycle).

### 📍 קטגוריה 2 — נכסים יצירתיים (10 פריטים)

#### Creatives (5)
- [ ] **9. וידאו 1 — Hook חזק 3 שניות**, אורך 15-30 שניות, עברית עם subtitles.
- [ ] **10. וידאו 2 — Variant** של Hook שונה (לבדיקת A/B).
- [ ] **11. תמונה סטטית 1** — Single image עם CTA ברור.
- [ ] **12. תמונה סטטית 2** — Carousel של 3-5 שקופיות.
- [ ] **13. UGC content** — לפחות 1 וידאו לקוח שמדבר.

#### Copy (5)
- [ ] **14. 3 וריאציות כותרת** — שונות במנגנון פסיכולוגי.
- [ ] **15. Primary text** ל-Meta — 3 וריאציות (קצר 50w / בינוני 100w / ארוך 200w).
- [ ] **16. CTA** — אחד ספציפי: "הירשם לוובינר", "קבל את המדריך", לא "למידע נוסף".
- [ ] **17. Headline (Display)** — 30 תווים מקסימום, נשען על Big Idea.
- [ ] **18. Lead form questions** (אם יש Lead Form) — 3 שדות מקסימום.

### 📍 קטגוריה 3 — דף נחיתה ותהליך (6 פריטים)

- [ ] **19. דף נחיתה ייעודי** — לא homepage. URL ספציפי ל-campaign.
- [ ] **20. דף נטען ב-<2 שניות** — בדוק עם PageSpeed Insights.
- [ ] **21. דף עובד מובייל מצוין** — 70%+ מ-traffic = mobile.
- [ ] **22. Form פשוט** — 3 שדות מקסימום. שם + מייל + שאלה אחת.
- [ ] **23. תודה page** — לא רק "תודה" — הוראה ברורה למה הלאה.
- [ ] **24. Sequence Email מוכן** — 5-7 מיילים אוטומטיים מתחילים ב-day 1.

### 📍 קטגוריה 4 — Tracking ומדידה (6 פריטים)

- [ ] **25. UTM parameters** מוגדרים — `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`.
- [ ] **26. Meta Pixel / Google Tag** מותקנים בדף הנחיתה ובדף תודה.
- [ ] **27. Conversions API** מוגדר (Meta) — סרבר-לסרבר tracking לעקיפת iOS 14.
- [ ] **28. Custom conversions** מוגדרים — Lead, Purchase, Add to Cart.
- [ ] **29. Google Analytics 4** מותקן + Goals מוגדרים.
- [ ] **30. דאשבורד יומי** — Google Sheet / Looker Studio שמסכם: Spend / CPL / CTR / CVR.

## תכנון הקמפיין — לפני ההפעלה

### תוכנית 14 הימים הראשונים
- **יום 0-3:** Learning phase — Meta/Google "לומדים" את הקהל. **לא לעצור.** גם אם נראה רע.
- **יום 4-7:** First optimization. כיבוי ad sets שעובדים גרוע משמעותית.
- **יום 8-14:** Scale ה-winners. שכפול ad sets שעובדים.

### תקציב יומי מומלץ
- **Test phase (חודש 1):** 5-10% מהתקציב החודשי ליום. אם תקציב ₪10K → ₪500-1,000/יום.
- **Scale phase (חודש 2+):** 100% מהתקציב חולק לפי best performers.

## KPI לבדיקה יומית

```
Day | Spend | Impressions | CTR | CPL | Leads | CVR | Cost/Sale | ROAS |
----|-------|-------------|-----|-----|-------|-----|-----------|------|
1   |       |             |     |     |       |     |           |      |
```

### Benchmarks (לעסק שירות B2B/B2C)
- **CTR (Click-Through):** 1.5-3% (Meta), 3-5% (Google Search).
- **CPL (Cost Per Lead):** ₪30-200 (תלוי בנישה).
- **CVR (Conversion to Sale):** 5-25% מ-leads.
- **Cost per Sale:** ≤ 30% מ-Lifetime Value הראשונה.
- **ROAS Day 14:** ≥1.5.
- **ROAS Day 60:** ≥3.

## דגלים אדומים — מתי לעצור

1. **CTR < 0.8%** — ה-Hook לא עובד. שנה Creative.
2. **CPL > 3x של benchmark** — ה-Targeting לא ממוקד או הקופי לא ברור.
3. **Lead → Sale < 5%** — בעיה במוצר / pricing / sales call. לא ב-Ads.
4. **ROAS < 1 אחרי 14 יום** — שריפת כסף. עצור.
5. **Frequency > 3.5** — אותו הקהל רואה את אותו האד יותר מדי. שנה Creative.

## טעויות נפוצות

1. **התחלת קמפיין בלי דף נחיתה ייעודי.** Traffic ל-homepage → CVR אפסי.
2. **Targeting רחב מדי.** "כולם בישראל" → ROAS אפסי.
3. **Targeting צר מדי.** רק 5,000 איש → ה-frequency עולה במהירות, Cost עולה.
4. **שינוי הקמפיין כל יום.** Meta לא מספיק "ללמוד" → Learning phase מתאפס.
5. **אין Sales Sequence.** Lead נכנס, אף אחד לא מתקשר → אבוד.
