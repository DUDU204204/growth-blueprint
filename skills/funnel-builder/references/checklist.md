# צ'קליסט - פאנל מכירה

> רשימת בקרה pre-launch. עוברים עליה לפני שמדליקים traffic. מבוסס על [METHOD.md](./METHOD.md). אסור em-dash, רק מקף.

## א. Value Ladder ומבנה
- [ ] מיפיתי את כל המדרגות הקיימות (Free → Frontend → Mid → High → Continuity)
- [ ] יש ≥3 מוצרים במחירים שונים (אחרת זה "מוצר + תקווה", לא פאנל)
- [ ] אין קפיצת מחיר לא-אנושית בין מדרגות (0 ל-10K = חסרה מדרגת ביניים)
- [ ] ה-Frontend מספק 20-30% מהערך - לא 80% (לא "חינמי-מדי")
- [ ] יש מדרגת Continuity ב-back-end (לא מתחילים מאפס כל חודש)

## ב. כניסה: Traffic + Lead Magnet
- [ ] מקור ה-traffic ברור (אורגני / ממומן) ויש לו תקציב/תוכנית
- [ ] Lead Magnet עם ערך גבוה וחיכוך מינימלי (קבלה מיידית)
- [ ] **UTM על כל לינק** שיוצא (פוסט, מייל, וואטסאפ) - אחרת אין שיוך מקור
- [ ] אין דף ללא exit-path (חוק נגד cul-de-sac)

## ג. דף נחיתה / Opt-in
- [ ] Hook חזק במעלה (לא "הירשם" - "תגלה איך X באופן Y בלי Z")
- [ ] הוכחה חברתית (מי אני, כמה אנשים, איזו תוצאה)
- [ ] טופס מינימלי (שם + מייל; טלפון רק אם השלב הבא שיחה)
- [ ] Thank-you page שולח Event "Lead" לפיקסל

## ד. מנוע ההמרה (Frontend / וובינר / שיחה)
- [ ] ההצעה מוכחת - 3 לקוחות עברו את המסילה ידנית וההצעה נסגרה
- [ ] Hook-Story-Offer קוהרנטי (אין סתירה בין הבטחת הדף לתוכן)
- [ ] משוואת הערך נבדקה (Dream Outcome / Likelihood גבוהים, Time / Effort נמוכים)
- [ ] אם וובינר - עבר את הצ'קליסט של הסקיל webinar-expert
- [ ] אם שיחה - יש סקריפט + disqualification

## ה. עמוד התשלום (עמדת השיטה - קריטי)
- [ ] דף מכירה עם הצעה אחת ברורה
- [ ] **Order Bump אחד** בעמוד התשלום (checkbox, מוצר משלים, משפט תועלת)
- [ ] **אין one-click OTO אגרסיבי** אחרי התשלום (בלי "כן/לא-אני-מוותר-לתמיד", בלי downsell שרשרת)
- [ ] סליקה עובדת (בדיקת רכישת-בדיקה end-to-end)

## ו. אחרי הרכישה
- [ ] Thank-you page עם סקשן רך "**אולי יעניין אותך גם**" (לא כופה, בלי טיימר לוחץ)
- [ ] מייל אישור + צעד ראשון + onboarding מיידי
- [ ] רצף Buyer Sequence מתוזמן (אישור / ברוכים הבאים / מה לעשות אם לא התחלת)

## ז. Ascension (פרוס בזמן, לא דחוס)
- [ ] מייל ל-Frontend buyers אחרי X ימים מציע Mid
- [ ] וובינר חודשי / שיחת מכירה מובנה ל-upgrade למדרגה הבאה
- [ ] offer-in-the-back רך אחרי כל מסירה
- [ ] לקוח High מקבל הצעת Continuity שמגנה על ההישג

## ח. מדידה ואבחון (לפני go-live)
- [ ] פיקסל Meta ירוק ב-Events Manager (PageView / Lead / Purchase)
- [ ] Thank-you page event פעיל
- [ ] מהירות דף <3 שניות (PageSpeed) - דף 6s = לא נוגעים בקופי, מתקנים מהירות
- [ ] Mobile rendering נבדק (אייפון + אנדרואיד; 80%+ מהתנועה מובייל)
- [ ] יודע למדוד conversion בכל קפיצת מדרגה (אחרת הפאנל קופסה שחורה)

## ט. בריאות כלכלית
- [ ] LTV מחושב על **רווח גולמי** (לא מחזור): מחיר × % רווח × רכישות ממוצע
- [ ] LTV/CAC ≥5 (שירות איכותי) או לפחות ≥3
- [ ] Money Model - ה-30 ימים הראשונים מכסים את ה-CAC (פאנל ממן את עצמו)
- [ ] CPL < ¼ מ-AOV

## י. סקירה סופית
- [ ] הסקיל `copy-supervisor` עבר על הפאנל המלא
- [ ] קריטריון יציאה: 3 לקוחות end-to-end + L2C ≥5% עם דאטה (לא "בנוי" - "הוכח")
- [ ] בכל הקופי: מקף `-` בלבד, אין em-dash
