# מקורות עיצוב לעבודה עם Claude Code

מקורות חיצוניים שמשמשים כספריית רפרנס לעיצוב - לבחירת קומפוננטות, סגנון אתר, ואנימציות - ואז הזרקת הפרומפט/הקוד חזרה ל-Claude.

הרעיון: במקום לתאר עיצוב במילים ("הופ עם זוהר וצללית קלה"), בוחרים פריט מהקטלוג, מעתיקים את הפרומפט/הקוד המוכן, ו-Claude ממשיך מהנקודה הזאת.

---

## 1) 21st.dev - ספריית קומפוננטות + אנימציות
- **URL:** https://21st.dev/home
- **מתי להשתמש:** צריך קומפוננטה ספציפית (hero, pricing card, navbar, button, modal, animation) - לא אתר שלם.
- **מה הוא נותן:** קטלוג של קומפוננטות בודדות עם code/prompts מוכנים להעתקה. גם פיצ'ר "Magic Chat" שמייצר וריאציות מתיאור.
- **קטגוריות עיקריות:** UI Components, Agent Templates.
- **חינמי** (בסיס). יש גם MCP רשמי (Magic MCP) למי שרוצה חיפוש מובנה מתוך Claude Code.

## 2) Refero Design (styles.refero.design) - רפרנסים של מותגי-ענק
- **URL:** https://styles.refero.design/
- **מתי להשתמש:** רוצים סגנון עיצוב של אתר שלם, בהשראת Apple / Linear / Samsung / מותגי ענק.
- **מה הוא נותן:** דוגמאות של דפים שלמים עם פרומפטים מוכנים, design tokens (color, typography, spacing, components), וקובץ DESIGN.md ייעודי ל-AI agents.
- **דרכי סיווג:** Brand, Mood, Color, Typography, URL. סקשנים: Trending / Popular / Newest.
- **חוזק:** לוכד את ה-"vibe" של מותג גדול בלי שצריך לתאר אותו במילים.
- יש MCP רשמי (דורש מנוי Pro בתשלום).

## 3) MotionSites.ai - אתרים עם scroll animations
- **URL:** https://motionsites.ai/
- **מתי להשתמש:** רוצים אנימציות גלילה, מעברים, חוויית WOW.
- **מה הוא נותן:** 100+ תבניות AI-designed עם הדגמה חיה ופרומפטים. כפתור "Copy" ליד כל אחד.
- **קטגוריות:** SaaS, Agencies, Portfolios, E-commerce, Web3.
- **חוזק:** הכי חזק לדף-נחיתה פרימיום שצריך "להפיל לקוח מהכיסא".

## איך לעבוד עם זה בפועל

### בקשה רגילה ("בנה לי דף נחיתה")
עובדים לפי ה-SKILL וה-METHOD כרגיל - בלי לחפש כאן.

### בקשה עם דרישה ויזואלית ספציפית
דוגמאות:
- "תעצב לי משהו בסגנון Apple" → **Refero**
- "אני רוצה hero עם אנימציה מטורפת" → **MotionSites** או **21st**
- "תן לי pricing table יפה" → **21st**
- "דף שמרגיש פרימיום עם הרבה תנועה" → **MotionSites**

תהליך (Claude עושה את הכל בעצמו, לא מטריח את המשתמש):
1. Claude עושה WebFetch לאתר הרלוונטי עם prompt ממוקד ("find me 3 hero sections with bold typography").
2. מציג למשתמש 2-3 אופציות עם תיאור קצר + לינק ישיר לפריט.
3. אחרי שהמשתמש בוחר - Claude עושה WebFetch לדף הספציפי, מוציא את הפרומפט/קוד, ומיישם.
4. מתרגם לקונטקסט: RTL, עברית, המותג של הלקוח.

### בקשה לרפרנס מהיר
"תראה לי דוגמאות של X" → WebFetch + סיכום + לינקים. לא רק "תיכנס ותראה".

---

## הערות עבודה

1. **אסור להתחייב על פריט ספציפי בלי לבדוק.** אם אתה "זוכר" שיש שם קומפוננטה מסוימת - לא להגיד את זה לפני WebFetch מאמת.
2. **התוכן באתרים משתנה.** לפעולה רצינית עדיף fetch טרי לכל בקשה.
3. **התאמת RTL היא לא אופציונלית.** רוב הקומפוננטות בקטלוגים בנויות LTR - כל אימוץ דורש היפוך כיוונים, בדיקת פיסוק עברי, ופונט תומך-עברית.
