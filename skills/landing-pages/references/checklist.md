# צ'קליסט - דף נחיתה

רשימת בקרה pre-flight לפני השקת דף נחיתה. עבור שלב-שלב. אל תזרים טראפיק לפני שכל הקטגוריות מסומנות.

## 0. הכנה (לפני כתיבה)
- [ ] אווטאר מוגדר (שם, 3 כאבים, 3 תקוות, המילים שלו)
- [ ] שלב מודעות (Schwartz) נקבע - Unaware / Problem / Solution / Product / Most
- [ ] רמת התחכמות השוק נבדקה (5-10 מתחרים) - הדף רמה אחת מעליהם
- [ ] Big Idea נוסח במשפט אחד
- [ ] ההצעה עומדת ב-5 הקריטריונים (מובנת/מדידה/בזמן/ערך/חדשנית)
- [ ] CTA יחיד הוגדר + KPI (CR/leads/EPC)

## 1. Hero / מעל הקיפול ("זה בשבילי?")
- [ ] כותרת = סקרנות + ספציפיות + רלוונטיות (לא קיטש, לא גנרית)
- [ ] כותרת מבטיחה תועלת ומתאימה לשלב המודעות
- [ ] תת-כותרת מרחיבה, לא חוזרת
- [ ] ויזואל Hero תומך, לא מסיח
- [ ] CTA ראשוני גלוי בלי גלילה
- [ ] Trust signal (מספר/לוגו) כבר מעל הקיפול

## 2. Hook ("זה שווה?")
- [ ] פתיחה נבחרה מ-11 הפתיחות
- [ ] רגש קודם, היגיון אחריו (לא פתיחה בתכונות/נתונים)
- [ ] לכאב יש שם (מיתוג הכאב)
- [ ] יש ניגוד - "רוב עושים X, אנחנו Y"

## 3. סיפור ואמון ("זה בטוח?")
- [ ] Epiphany Bridge - 7 רכיבים, אמיתי (לא מומצא)
- [ ] ברור מי אתה ולמה דווקא אתה (ביסוס, לא הצהרה)
- [ ] אורך מתאים לקהל (Cold = ארוך, Hot = קצר)

## 4. הצעה ("זה יעבוד אצלי?")
- [ ] ההצעה ב-X Y Z או באחת מ-3 התבניות
- [ ] Value Stack גלוי - רכיב + ערך + סה"כ
- [ ] אפקט האווז - מחיר עוגן **אמין** לפני הרצוי
- [ ] USP חד שמתחרה לא יכול לומר

## 5. הוכחות
- [ ] 3+ עדויות עם שם + תמונה + תוצאה ספציפית
- [ ] Before/After עם מספרים
- [ ] Social Proof במספרים + לגיטימציה (3-5 חזקים)
- [ ] דמונסטרציה ויזואלית (סקרין-שוט/וידאו)
- [ ] הוכחה ממוקמת ליד נקודות החלטה (סמוך ל-CTA)

## 6. התנגדויות + CTA ("מה אם לא?")
- [ ] FAQ - 5-7 התנגדויות אמיתיות עם תשובות
- [ ] Risk Reversal - אחריות/החזר/ניסיון
- [ ] דחיפות אמיתית בלבד (אין טיימר מזויף, אין "נשארו 2" ללא בסיס)
- [ ] CTA סופי תוצאתי, פעולה יחידה

## 7. טכני + ניקוי
- [ ] מובייל: viewport meta, inputs ≥16px, כפתורים לאצבע
- [ ] טעינה <2.5s LCP, PageSpeed >80 במובייל
- [ ] טופס - מינימום שדות הכרחיים
- [ ] **אין cul-de-sacs** - הוסר תפריט, לינקים החוצה, כל מסיח
- [ ] UTM + מדידת המרה פעילים

## 8. קריא ברפרוף (חוצה-דף)
- [ ] מבחן הרפרוף: קריאת המודגש בלבד - עדיין מבינים את ההצעה?
- [ ] Bold למילים נושאות-מסר, bullets במקום פסקאות, רווח לבן סביב משפט קריטי
- [ ] אין em-dash בשום מקום בקופי. רק מקף רגיל (-)

## 9. סופרוויזר (לפני שיגור)
- [ ] הסקיל `copy-supervisor` רץ על הדף (CRO + קופי)
- [ ] cross-check מול שפה-ומושגים - כל עיקרון מרכזי קיים או נשקל
