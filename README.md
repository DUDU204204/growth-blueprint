# 🧭 Growth Blueprint — מצפן הצמיחה של דודו נחום

חבילת סקילים ל-Claude Code שמלמדת את הקלוד שלך את המתודולוגיות השיווקיות והעסקיות המלאות: קופירייטינג, וובינרים מוכרים, דפי נחיתה, פאנלים, עיצוב הצעות, מחקר אווטאר, אודיט CRO ומפת הליווי העסקי.

## התקנה (2 דקות)

פותחים Claude Code ומריצים:

```
/plugin marketplace add DUDU204204/growth-blueprint
/plugin install growth-blueprint@dudu-nahum
```

זהו. מעכשיו הקלוד שלך מכיר את השיטה.

## מה מקבלים

| סקיל | מה הוא עושה |
|------|--------------|
| `copy-supervisor` | סופרוויזר קופי — בודק ומשדרג כל נכס שיווקי לפי 70+ עקרונות |
| `webinar-expert` | בונה וסוקר וובינרים מכירתיים |
| `email-marketing` | ניוזלטרים ומיילים שיווקיים מחומר גלם |
| `landing-pages` | דפי נחיתה ממירים |
| `funnel-builder` | פאנלים ומשפכים |
| `offer-design` | עיצוב הצעות (Grand Slam) |
| `avatar-research` | מחקר קהל ואווטאר |
| `advertorial` | אדוורטוריאלים וכתבות שיווקיות |
| `cro-audit` | אודיט המרות לאתר קיים |
| `site-spec` | איפיון אתר מכירתי מלא |
| `growth-compass` | מצפן הצמיחה — אבחון עסקי, 15 צעדים, 31 כלי ייעוץ |

## איך עובדים עם זה

פשוט מבקשים מהקלוד בשפה חופשית: "תבנה לי וובינר למוצר X", "תעבור על דף הנחיתה שלי כסופרוויזר", "תאבחן את העסק שלי על מצפן הצמיחה". הקלוד יטען את הסקיל הרלוונטי לבד.
